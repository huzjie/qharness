# Hand Brain Separation

# 手脑分离

- **脑（brain）**：模型调用、规划、工具选择、循环控制。低并发、高延迟、吃显存。
- **手（hand）**：工具执行。高并发、要隔离、要限资源。

两者只通过 `tool_call` / `tool_result` 事件通信。

## 好处

1. 脑部署在 GPU 节点，手部署在 CPU 沙箱节点，各自独立扩容。
2. 危险命令（rm -rf）由手的沙箱拦截，不会拖垮模型服务。
3. 脑/手可以独立演进、独立灰度。

## 工程技巧

给手的每个工具统一加「超时 + 白名单 + 资源上限」三层防护，这是编码智能体安全性的底线。
